About this reference

Warp is a Rust game engine and editor. A game is a crate that names one dependency, warp_sdk, and implements one trait. Warp Wiki documents that SDK: each library has an article that explains how it works, and each article ends with a reference to every public item, read directly from the source.

Where to start

  • Getting started takes a new project from the starter to a first run.
  • Renderer and run covers the entry point and the frame loop.
  • Smoke tests prove that a game boots with no window and no GPU.
  • Squircle kit is the default interface of a Warp app.
  • Art direction sets the rules for text, menus, fonts, and light.

Search covers every article and every public symbol. Press / to start.
