Shader catalog

Every WGSL file in the shader library, grouped by family.

Every WGSL file in warp_sdk/shaderlib/, one line each. Pick by tag, then compose by path:

let wgsl = warp_sdk::shaderlib::compose(&["material/stone.wgsl"]);

Format of a line: path — what it gives — fn names — tags.

core

  • core/material.wgsl — the MaterialSample surface record — material_default — surface, pbr

  • noise/value.wgsl — value noise 2D/3D in [0,1] with analytic derivative, tileable — noise_value2/3, noise_value2d/3d, noise_value2d_tiled, noise_value3d_tiled — value, lattice, derivative, normal, tileable
