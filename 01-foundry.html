The toolkit

Six tools. No glue code.

Every part ships in the box and talks to the others. No plugins to hunt down before you can make a game.

01 · Live Patch

Hot reload that keeps state

Edit code, textures, audio, and shaders while the game runs. Positions, timers, and enemy AI keep going.

~140 ms median patch, 2,000-file project
02 · Parts Bin

Drag in. Done.

Drop .blend, .fbx, .gltf, .png, or .wav. Scrap imports, builds LODs, and packs atlases on save.

0 import dialogs sensible defaults, override per file
03 · Wiring

Nodes that compile

Visual scripting for designers that compiles to readable native code. Engineers can open the output and edit it.

1:1 graph to source, round-trip safe
04 · Chassis

Data-oriented core

An ECS runtime laid out for the cache. Big crowds, bullet hell, and sims stay smooth on old hardware.

100k entities @ 60 fps, 2019 laptop
05 · Ship It

One click, five targets

Export to Windows, macOS, Linux, Web, and Steam Deck from one build profile. Signing and icons included.

5 targets reproducible builds, CI-ready CLI
06 · Teardown

See every millisecond

A frame profiler with per-system timings and spike capture. Click a spike to jump to the line that caused it.

per-system timings, zero setup
