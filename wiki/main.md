## About this reference

**[[scrap|SCRAP]]** is a Rust game engine and editor. A game is a crate that names one dependency, `warp_sdk`, and implements [[renderer|one trait]]. SCRAP Wiki documents that SDK: each library has an article that explains how it works, and each article ends with a reference to every public item, read directly from the source.

## Where to start

- [[getting-started|Getting started]] takes a new project from the starter to a first run.
- [[renderer|Renderer and run]] covers the entry point and the frame loop.
- [[smoke|Smoke tests]] prove that a game boots with no window and no GPU.
- [[squircle|Squircle kit]] is the default interface of a SCRAP app.
- [[art-direction|Art direction]] sets the rules for text, menus, fonts, and light.

Search covers every article and every public symbol. Press <kbd>/</kbd> to start.
