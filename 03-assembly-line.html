Station 02 / Wiring

Wire it in nodes. Read it as code.

Wiring is node-based scripting for designers. Every graph compiles to readable native code, so a programmer can review it, diff it, and step through it.

EventOn Input · Jump
BranchIs Grounded?
Readtuning.jump_height
ActionImpulse + clank.wav
// generated by Wiring · player_jump.rs
pub fn player_jump(
    input: Res<Input>,
    mut q: Query<(&mut Velocity, &Grounded, &Tuning)>,
    audio: Res<Audio>,
) {
    if !input.just_pressed(Action::Jump) { return; }
    for (mut vel, grounded, tune) in &mut q {
        if grounded.0 {
            vel.y = tune.jump_height;
            audio.play("clank.wav");
        }
    }
}
